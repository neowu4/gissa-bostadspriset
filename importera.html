🏠 Gissa bostadspriset

Lägg till fler bostäder

Booli blockerar automatiska skript, så importen körs i din egen webbläsare medan du är inne på Booli. Den läser slutprisresultatet du har framför dig och sparar bostäderna som en fil.

Med bokmärke (enklast)

  1. Dra knappen till bokmärkesfältet:

    🏠 Importera till Gissa bostadspriset
  2. Gå till booli.se/sok/slutpriser och sök på ett område. Filtrera gärna på bostadstyp.
    Tips: de allra senaste försäljningarna saknar ofta bilder. Läs från sidan 10 och framåt, eller lägg till &maxSoldDate=ÅÅÅÅ-MM-DD (några veckor bakåt) i adressen, så får du fler bostäder med bilder.
  3. Klicka på bokmärket. En ruta dyker upp i hörnet. Välj hur många sidor som ska läsas och tryck på Starta. Byt gärna sökning och kör igen, bostäderna samlas ihop.
  4. Tryck på Ladda ner. Filen kan du antingen ladda in direkt i lobbyn (ladda egen fil) eller lägga in i spelet för alla (se nedan).

Utan bokmärke (t.ex. Safari)

Öppna Booli, öppna utvecklarkonsolen och klistra in koden:

Lägg in i spelet för alla

Slå ihop den nedladdade filen med spelets bostadslista och pusha till GitHub:

node scripts/merge.mjs ~/Downloads/bostader-*.json

Skriptet tar bort dubbletter och sparar till data/listings.json. Kör sedan git commit och git push, så uppdateras GitHub Pages.

All data och alla bilder tillhör Booli och mäklarna. Använd importen måttligt.
